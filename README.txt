PUBLIC WEBSITE:
This package is ready for GitHub Pages. Create a public GitHub repository, upload
index.html and profile.png, then enable Settings > Pages > Deploy from a branch,
select main and /(root). Your public address will be:
https://YOUR-GITHUB-USERNAME.github.io/REPOSITORY-NAME/

GitHub Pages is a public static website host. Publishing may take a few minutes.
